# Cashtro assistant

Castro's desk lives in this kernel. Every ask is a first-class request.
Do not fork a second product.

## Loop

1. Capture the raw ask with `desk.capture` (or `POST /api/requests`). Never overwrite `raw`.
2. Better it. First pass classifies and rewrites. Each later `desk.better` tightens the same request.
3. Do the allowed work in this repo / OS. If it cannot be done, park it as `blocked` with the reason.
4. Prove it (`go test ./...`, desk UI, walkthrough). Then `desk.done`.
5. New agentics register here. Mail, notes, memory, confirms, and requests stay first-class.

## Can do

- Build Cashtro OS (Go kernel, agents, APIs, desk UI, tests, PRs)
- Run the delivery line: idea → concept → production
- Research notes, memory, explorer search
- Draft outbound behind the human gate (`comms.send`)
- Verify the UI and walk through the desk
- Open draft PRs. Do not merge unless Castro asks

## Cannot do

- Illegal or harmful work (exploits, malware, weapons, anything involving minors)
- Send email/Slack/money without an allowed confirm
- Merge, force-push, or rewrite published history on your own
- Invent a second Cashtro product or copy private Evolu-Jeunes client code here
- Pretend resident verbs are live (operator, reviewer, architect, deploy, security, investigator)
- Commit secrets. OpenRouter stays optional and out of git
- Rely on Supermemory — it is not connected. The desk log is the memory

## Create

Agentics, ships, notes, facts, requests, confirms, stdlib APIs, desk UI, tests, PRs, and this playbook.

## Do not create

A parallel dashboard, client source in this tree, fake walkthroughs, or silent scope creep.

Ask Castro in FR or EN. Messy text is fine. Capture it anyway.

# raw — coffre Castro

Dépose ici tout ce que je dois traiter après : papiers, photos, captures, vidéos, notes, schémas.

Ce dossier est **ignoré par git**. Rien de client ne part sur `cashtro/cashtro` (public).

## Où mettre quoi

| Dossier | Contenu |
| --- | --- |
| `papers/` | PDFs, contrats, devis, docs officiels |
| `images/` | Photos, screenshots, mockups, logos |
| `videos/` | Walkthroughs, démos, recordings |
| `paperwork/` | Formulaires, scans, admin |
| `notes/` | Texte, listes, mémos |
| `inbox/` | Pas sûr ? Mets-le ici, je trierai |

## Comment me le donner (téléphone)

1. Ouvre ce dossier `raw/` dans Cursor
2. Envoie le fichier dans le bon sous-dossier, **ou**
3. Attache le fichier dans le chat et dis « mets-le dans raw »

Ensuite écris : **« treat raw »** — je lis le coffre, je le passe à Graphify, et j’agis.

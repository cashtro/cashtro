# PBTM — Panda Business Tech & Marketing

Sauvegarde des pages et des fichiers de marque produits avec Claude.

| Fichier | Rôle |
|---|---|
| `centre-de-commande.html` | Source de l'artifact « Centre de commande » (https://claude.ai/artifact/KfJYjsKrX6zH7fomAhE9k1). |
| `logos.html`, `logos/` | Planche et fichiers SVG des logos PBTM (A pour le site, C comme badge). |
| `identites.html` | Planche des 3 directions de marque explorées (Signature, Confiance Tech, Aurora). |
| `agents/` | Les 49 fiches d'agents (nom, équipe, rôle, outils, méthode). |
| `recherche-*.md` | Recherches : outils IA, délibération multi-agents, noms, tirages, NFT. |
| `mock*.js`, `run-*.cjs` | Faux runtime et tests Playwright du Centre de commande. |

Le code du site (espace client, admin, moteur d'agents) est dans le dépôt cashtro/CSI, branche `plateforme`.
